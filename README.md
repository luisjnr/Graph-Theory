# Graph Theory

Repository dedicated to the study and practice of Graph Theory using Python.

It contains exercises and implementations developed throughout the course, covering fundamental graph concepts and different graph representations.

## Content

### Matrix

Implementations related to graph representation using matrices, including:

- Adjacency Matrix
- Incidence Matrix
- Adjacency Dictionary
- Conversion between graph representations
